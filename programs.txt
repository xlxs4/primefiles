from Run: shell:startup
create a startup.bat in the startup dir and add
@echo off

make a misc and a code dir. In misc, create a shell.bat:
@echo off
call "C:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools\VC\Auxiliary\Build\vcvarsall.bat" x64
set path=w:\hh\misc;%path%

devenv is available from the visual studio install. Both the, e.g., Community edition and Build Tools co-exist, in different dirs. So, to get devenv, point to the correct vcvarsall:
call "C:\Program Files\Microsoft Visual Studio\18\Community\VC\Auxiliary\Build\vcvarsall.bat" x64

and also grab a copy of the command prompt shortcut, put it in misc, go to the shortcut properties, in target append /k w:\hh\misc\shell.bat after cmd.exe, and do, e.g., start in w:\hh

also add a sb.bat in misc with:
@echo off
subl --project w:\hh\hh.sublime-project

make sure you have created the sublime project file

a build.bat:
@echo off

if not exist build mkdir build
pushd build
cl -Zi -FC ..\code\win32_hh.cpp
popd

you can also pass things like nologo to cl, refer to, e.g., https://github.com/EpicGames/raddebugger/blob/master/build.bat

make a data dir as well, open the exe in visual studio with devenv build\myexe.exe, go to the properties in the solution explorer, and set the working directory to the data dir, using the subst drive (w:\...\data)
